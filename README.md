# NECSTORY

**Real ghost, crime, dark web & mystery stories — live, no login.**

A red/black/white glassmorphism story-discovery engine for creators. Pick a darkness, get real stories from live sources, or hit **Surprise Me** for a random tale.

## Pages

| Page | What it is |
|---|---|
| `index.html` | Home — animated hero, six story realms, live sources |
| `stories.html` | The Archive — search, browse & read every story in-app |
| `about.html` | Mission, sources & rights, accuracy labels, socials |

Every story opens **inside the website** in the glass story-reader — full text is fetched live from the source API. No redirects, no new tabs.

## Live sources (all keyless public APIs)

| Source | What it powers |
|---|---|
| Wikipedia API (Hindi + English) | Ghost locations, unsolved crimes, mysteries |
| Creepypasta Wiki (Fandom API) | Ghost / crime / dark-web story vault |
| Project Gutenberg | Pre-1930 public-domain horror & crime classics |
| GitHub datasets (bundled) | 2,000 horror seeds · 53 Hindi classics |
